# Contributing

Read the README, security policy, and existing tests before changing behavior.

- Preserve one rules authority.
- Add regression tests for mechanics bugs.
- Keep the plugin offline and state outside the checkout.
- Do not add privileged or network behavior without a documented architecture
  decision and maintainer review.
- Use Omarchy theme tokens and keyboard/mouse parity.
- Test 1280×800 layouts.

Run:

```bash
./scripts/validate.sh
```
