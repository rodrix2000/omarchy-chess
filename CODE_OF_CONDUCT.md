# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Omarchy Chess a respectful, harassment-free experience for everyone, regardless of background, identity, experience level, or ability.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on code, behavior, and evidence.
- Welcome beginners and explain project conventions.
- Respect privacy when users provide game records or diagnostics.
- Credit contributors and third-party work appropriately.
- Accept maintainers’ decisions about V1 scope and release safety.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks
- Publishing private information without permission
- Deliberately submitting malicious code, credentials, or unsafe assets
- Repeatedly derailing work after a documented decision
- Misrepresenting test results, licenses, or chess correctness

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this code. Serious concerns should be reported privately through the repository’s security/contact channel.

## Scope

This code applies in project repositories, issue trackers, discussions, pull requests, and other spaces where a person represents the project.
