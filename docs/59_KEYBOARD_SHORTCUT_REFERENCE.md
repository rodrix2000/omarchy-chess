# Keyboard Shortcut Reference

## Global panel

| Key | Action |
|---|---|
| `Esc` | Cancel current transient state, then pause/close context |
| `?` / `F1` | Help |
| `Tab` / `Shift+Tab` | Move focus |

## Board

| Key | Action |
|---|---|
| Arrow keys | Move board cursor |
| `H` `J` `K` `L` | Vim-style cursor movement |
| `Enter` / `Space` | Select piece or commit destination |
| `Esc` | Cancel selection |
| `F` | Flip board |
| `U` | Request undo |
| `P` | Pause/resume menu |
| `D` | Draw actions |
| `Ctrl+R` | Resign confirmation |
| `N` | New-game confirmation |

## Promotion

| Key | Action |
|---|---|
| `Q` | Queen |
| `R` | Rook |
| `B` | Bishop |
| `N` | Knight |
| `Esc` | Cancel uncommitted promotion move |

## Replay

| Key | Action |
|---|---|
| Left / Right | Previous / next ply |
| Home / End | First / last position |
| `F` | Flip board |
| `C` | Copy PGN, when not conflicting with text input |
| `Esc` | Return to history/game |

## Text fields

When a text field is focused, ordinary letters belong to the field. Global destructive shortcuts require modifiers or are suspended.

## Customization

V1 may use fixed internal shortcuts. A future release can add remapping after accessibility and conflict handling are designed.
